# ML Anomaly Detection for Energy Consumption

Модуль для обнаружения аномалий в данных потребления электроэнергии с использованием алгоритма Isolation Forest.

## Описание

Данный проект реализует автоматическое обнаружение аномалий во временных рядах энергопотребления. Система разбивает данные на временные окна, извлекает статистические характеристики и использует алгоритм Isolation Forest для идентификации аномальных паттернов поведения.

### MLModel

Класс, реализующий логику обнаружения аномалий:

#### Параметры инициализации

| Параметр | Тип | Значение по умолчанию | Описание |
|----------|-----|----------------------|----------|
| `contamination` | float | 0.005 | Ожидаемая доля аномалий в данных (0.5%) |
| `window_size` | int | 1000 | Размер окна для агрегации данных |
| `threshold` | float | 0.25 | Порог для классификации статуса (25% аномальных окон) |

#### Основные методы

- **`fit_predict(data: pd.DataFrame)`** - обучение модели и предсказание аномалий
- **`predict_frame_status(data: pd.DataFrame)`** - определение общего статуса ("anomaly"/"stable") на основе доли аномальных окон
- **`_data_preparation(data: pd.DataFrame)`** - подготовка данных и извлечение признаков (внутренний метод)

### Процесс извлечения признаков

Для каждого временного окна (размером `window_size`) вычисляются следующие статистические характеристики для каждого сигнала:

- **RMS** - среднеквадратичное значение
- **Std** - стандартное отклонение
- **Max** - максимальное абсолютное значение
