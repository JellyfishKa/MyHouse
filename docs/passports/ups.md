# Паспорт оборудования: ИБП

**Категория:** `ups`  
**Метка в системе:** ИБП  
**Система мониторинга:** ПУЛЬСТОК

---

## Описание

Источники бесперебойного питания (On-line double-conversion).
Входной выпрямитель вносит гармоники тока; качество определяется
топологией (6-pulse vs. 12-pulse vs. IGBT PFC).

---

## Технические характеристики

| Параметр | Значение |
|---|---|
| Номинальная мощность | 1 000 – 20 000 ВА |
| Напряжение питания | 220 В / 380 В, 50 Гц |
| КПД (online-режим) | 92 – 96 % |
| Коэффициент мощности нагрузки | 0,8 – 0,95 |
| КНИ входного тока (THD-i) | 20 – 35 % |
| Время переключения | 0 мс (double-conversion) |
| Тип батарей | AGM VRLA, Li-Ion (опц.) |

## Диагностические признаки (NILM)

- **Сигнатура:** постоянная базовая нагрузка + импульс заряда батарей после провала питания.
- **Рабочий режим:** стабильная нагрузка, изменяется при смене нагрузки ИТ-оборудования.
- **Доминирующие гармоники:** 3-я (24,8 %) и 5-я (14,3 %) — маркер 6-пульсного ИБП.
- **Признак разряда батарей:** скачок нагрузки при переходе на батареи (инвертор).
- **Признак деградации батарей:** сокращение времени автономной работы; рост температуры батарейного блока.

---

## Примечания

Классический 6-пульсный ИБП даёт высокую 3-ю гармонику (особенно в однофазных устройствах).
IGBT-PFC-ИБП значительно снижает THD до 5–10 %.
При выборе ИБП для датацентра рекомендуется THD-i < 10 % для снижения нагрева нейтрального провода.
