# Паспорт оборудования: Освещение

**Категория:** `lighting`  
**Метка в системе:** Освещение  
**Система мониторинга:** ПУЛЬСТОК

---

## Описание

Светодиодные светильники с электронными драйверами.
Современные LED-драйверы имеют низкий THD (< 20 %) и высокий коэффициент
мощности при наличии PFC в драйвере.

---

## Технические характеристики

| Параметр | Значение |
|---|---|
| Номинальная мощность | 20 – 500 Вт (на линию) |
| Напряжение питания | 220 В, 50 Гц |
| КПД драйвера | 88 – 95 % |
| Коэффициент мощности | 0,90 – 0,97 |
| КНИ (THD) | 5 – 20 % |
| Цветовая температура | 3 000 – 6 500 К |
| Диапазон диммирования | 0 – 100 % (DALI / 0–10 В) |

## Диагностические признаки (NILM)

- **Сигнатура включения:** мгновенное ступенчатое нарастание (≤ 0,1 с).
- **Рабочий режим:** стабильная нагрузка с незначительным дрейфом < 2 %.
- **Доминирующие гармоники:** 3-я (10,4 %) — основной маркер LED-драйвера.
- **Диммирование:** снижение яркости до 10–30 % увеличивает THD; изменяется форма спектра.
- **Признак деградации:** рост потребляемой мощности при фиксированной яркости → деградация LED-кристаллов или драйвера.

---

## Примечания

LED-освещение значительно чище ламп накаливания (почти линейная нагрузка) и
ЭПРА люминесцентных ламп (высокий THD).
Характерная сигнатура: строгие ступени при включении/выключении групп светильников.
При использовании диммирования по DALI сигнатура меняется плавно.
